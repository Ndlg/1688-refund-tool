# 1688 退款详情工具

Edge 扩展，用于打开旧版 1688「待卖家确认收货」订单的详情页，并从退货物流轨迹检查签收。

## 安装或更新

1. 下载本仓库，打开 Edge 的 `edge://extensions/`。
2. 开启开发人员模式，选择「加载解压缩的扩展」，选中 `edge-extension` 文件夹。
3. 已安装时，更新该文件夹后，在扩展管理页面点「重新加载」。使用多个 Edge 配置时，在各配置中分别安装或重新加载。

## 日常使用

1. 在需要处理的 Edge 配置里登录 1688，打开卖家工作台的退款退货管理页。若页面显示「返回旧版」，可先切到旧版。
2. 点击扩展图标，在工作台输入 1688 页头显示的店铺名。扩展核对当前列表账号，并记住本配置上次使用的店铺名。
3. 点击「打开待收货并检查签收」，自动读取「待卖家确认收货」列表，复用当前窗口已打开的详情页，按 3 秒间隔补开缺失页，并逐单检查退货物流。
4. 若只需要部分详情页，点击「仅扫描订单」后勾选对应订单，再点「打开勾选的详情页」。也可以按签收结果筛选，用表头复选框全选当前列表。已选数量会提示筛选外仍被勾选的订单。
5. 在「签收地点关键词」填写仓库名、门店名或地址片段，多个关键词用逗号分隔，然后保存。关键词按店铺保存在浏览器内，匹配已签收或已取件的最新轨迹。
6. 每条订单的退货运单号单独展示。同一运单出现在多条订单中时，相关行会高亮并显示重复次数。复制结果也会带上重复运单号。

## 如何读结果

- **已签收**：最新退货轨迹明确显示已签收或已完成取件。
- **尚未签收**：最新退货轨迹显示在途、派送或入柜待取等。
- **无物流**：详情页确认未提供退货运单，或平台明确提示查不到轨迹、超过查询期限。
- **待核实**：轨迹冲突、拒收退回、存在多个运单，或只有模糊的代收信息。
- **读取失败**：详情页未加载、访问失败或轨迹格式未识别。可点击「重试未完成」。

签收结果来自快递轨迹，仓库验收和平台确认收货仍由商家处理。工作台的「手动工具」保留了原有的单号扫描、模板生成和逐个打开功能。
